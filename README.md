## 六大分頁研究架構（2002–2026・100% 真實權威數據・零前視偏誤）

1. **總覽與即時訊號**：最新月營收（含美元實質成長與匯率拆解）、季度 EPS／毛利率、PIT 即時 PER／PBR、24 年雙圖聯動全景與雙軌定態領先落後檢定（Bartlett 自相關修正 CI ＋ Newey-West HAC）。
2. **月營收動能回測（298 期）**：嚴格區分「公告前提前反應（T-20→T0）」「隔日跳空（T0→T+1）」與「公告後零前視可交易波段（T+1→T+60）」，支援 YoY / 滾動 3M QoQ / MoM / 谷底翻揚拆解、3×3 樣本數保護熱力圖與點擊散佈點逐日軌跡圖。
3. **季度 EPS 與法說會效應（99 季 / 88 場 SEC 6-K 精確法說日）**：區分季末營收後純暖身段、毛利率季變動（ΔGM）與 EPS 成長四象限實證及點擊法說會軌跡剖析。
4. **策略淨值回測與互動實驗室**：6 大經濟原型策略對決長期買進持有 2330（精確狀態轉移扣台股手續費與 0.3% 證交稅＋2010–2018 / 2019–2026 分段驗證）。
5. **PER × 成長估值矩陣**：PIT 即時法說 TTM PER 與股價淨值比 PBR（滾動 3Y 零前視分位）雙軌對照，剖析循環股低 PE 見頂陷阱。
6. **完整歷史明細帳與法證稽核**：全部 298 期月營收與 99 季法說會可搜尋明細（點擊即展開軌跡）與 5 模型審查修正紀錄。
